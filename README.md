# Community Aid Hub

Build a mobile-first React + Tailwind CSS web app called "Community SOS" — a real-time emergency coordination platform. Create the following pages/routes with placeholder content for now:- / (Home) — big red "SOS — PRESS FOR HELP" button, list of nearby active incidents below it- /login and /register — simple auth forms (name, email, phone, password)- /profile — shows user's platform ID, verification badges, profession, skills list, and a Volunteer Mode toggle- /incident/:id — incident room with a map placeholder, chat placeholder, and status line- /hospital-dashboard — list of incoming incidents with Acknowledge buttons- /admin — dashboard with 4 stat cards (Active Emergencies, Volunteers Online, Connected Hospitals, Flagged Reports) and a map placeholder Use a clean emergency-services color scheme (deep red for SOS/critical actions, white/light gray background, a calm blue for informational elements). Use React Router for navigation. Keep components modular — I'll be connecting real data next.
